# 公开数据可行性：文档核查

日期：2026-10-04。来源为研究子任务对四份官方资料的核查；本记录不代表本地应用已接通接口或完成真实商品搜索。

## 已核查的接口与来源边界

| 来源 | 文档提供的事实 | 对本产品的边界 |
| --- | --- | --- |
| [淘宝产品搜索](https://developer.alibaba.com/docs/api.htm?apiId=5) | taobao.products.search 用于天猫发布商品所需的产品信息搜索，并非商品搜索，标注需要授权。 | 不能直接拿该接口承担选品搜索；特定接口限制不代表整个淘宝来源不可搜索。 |
| [淘宝客推广者物料搜索](https://developer.alibaba.com/docs/api.htm?apiId=35896) | 文档描述关键词、类目、价格等筛选，以及标题、店铺、链接等字段；标注免费、不需要用户会话授权，但要求应用标识、签名和推广位。 | 不等于匿名可用或覆盖全量商品；实际准入、版本、额度与字段返回尚未验证。 |
| [抖音电商插件小程序能力清单](https://partner.open-douyin.com/docs/resource/zh-CN/mini-app/open-capacity/Industry/online-retailers/capacity-inventory) | 特定商品详情、评价、列表能力需绑定账号并申请权限。 | 该小程序能力不等于个人本地网页已有访问资格，也不构成其他公开渠道不可检索的证明。 |
| [抖音 robots.txt](https://www.douyin.com/robots.txt) | 存在针对不同爬虫和路径的抓取限制。 | 不能据此推断实际收录率、页面可读性或接口授权；实现前需按实际访问路径复查。 |

## 尚未实测

- 电商商品页面和站外搜索结果的实际可读字段、登录条件、覆盖与稳定性。
- 可核查需求证据、竞争材料的获得率，以及字段更新时间和统计口径。
- 京东、拼多多、小红书等其他来源；本次代表性核查只涉及淘宝/天猫和抖音。
- 官方接口的实际准入和调用；当前没有已接通的接口。
- 月 100 元运行费是否成立：需要搜索频次、实际单次费用和重试记录。

## 建议的数据验证方法（待确定实施范围）

- 选少量细分类目与关键词，区分发现链接、成功打开、取得有效字段三个阶段，并记录失败。
- 保存可追溯的来源 URL、对应字段、规格、店铺、价格口径、来源时间和核查时间。
- 搜索摘要仅视为线索；未打开并核对原页面的字段不标为已验证事实。
- 互动数量不转换为销量，搜索结果数量不表示整个市场竞争规模。
- 成本和销量缺失时保留未知，不使用文档示例值或演示值代替真实数据。
- 记录单次费用，再按预期月搜索量估算运行费；未接通接口不计入已实现覆盖。

最低结果数量、最大等待时间和月搜索频次尚未与用户约定；本记录不作可用性或覆盖承诺。
