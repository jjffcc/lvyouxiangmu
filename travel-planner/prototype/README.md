# 途见 · 国内旅游规划（演示原型）

## 第一版静态交互网站

按当前总需求文档制作的六模块演示版位于 [`v1/index.html`](./v1/index.html)。单文件版可直接双击 [途见-双击打开.html](./v1/途见-双击打开.html)，无需启动服务。打开时先显示静态登录界面；登录只检查输入是否填写，不验证或保存账号密码，也可直接进入演示。此处仅演示页面外观与通用交互，不代表真实认证已实现；正式登录、注册和会话逻辑以 S01 规格为准。交互信息仅在本次打开期间有效，刷新或关闭后恢复演示数据。页面使用示例数据，高德店铺查询与路径规划尚未接入。

这是需求文档对应的本地可点击原型。全部数据为虚构示例，未接入地图、天气、账户、AI、OCR 等真实服务，不能用于实际出行。

2026-10-05 更新：网页同步需求文档 v1.1，首页和设置页区分方案确认、演示完成、真实服务待接入及尚未上线；完整文档可通过 `requirements.html` 阅读、打印和下载。导航、操作、筛选及弹窗按钮使用与功能对应的不同图案，保留文字。

同时修复重复渲染后主内容容器积累点击监听的问题，避免一次点击重复执行多个页面的操作。

## 打开方式

最简单：双击 [途见-双击打开.html](./v1/途见-双击打开.html) 即可查看单文件离线版，无需启动服务。页面代码和照片已内嵌，但外部地图链接需要网络。

方式一：直接双击 `index.html`。原型不使用构建工具，也不需要安装依赖。

方式二：启动本地静态服务器（推荐，便于手机同网访问）：

```
python -m http.server 8771 --directory "D:\lvyouxiangmu\travel-planner\prototype"
```

然后访问 http://127.0.0.1:8771/ 。

## 原型覆盖范围

18 类页面：我的旅行、新建旅行、目的地发现、目的地特色、城市美食、资料库、行程工作台、方案对比、地图路线、地点详情、订单中心、订单导入确认、费用与分账、同行者、出行准备、途中助手、旅行回顾、设置与数据。

两条演示主线：杭州亲子三日游（含亲子硬性条件与美食/钓鱼特色）、成都重庆朋友多城市行（含跨城衔接与分账）。

可以实际操作的交互：页面导航、行程排序与锁定、AI 改线前后对比弹窗、城市美食的餐段与忌口筛选、订单类型筛选、订单导入确认与重复提示、费用分摊与结清、角色权限（只读角色会禁用编辑）、目的地搜索与空状态。

## 演示角色

右上角可切换“旅行负责人 / 可编辑成员 / 只读成员”。切到只读成员后，编辑、确认与保存类操作会提示不可用，用于验证权限差异。

## 明确未实现的部分

- 地图、路线与定位：页面为示意，跳转外部地图只弹说明弹窗。
- 天气：演示数据；远期日期显示“尚不可预报”。
- 账户、同步、邀请与权限：仅演示流程，不连接服务器。
- AI 规划与订单 OCR：使用预设内容演示，不上传文件、不调用模型。
- 离线与推送：只展示版本、保存时间和使用限制；不申请通知权限，不缓存真实数据。
- 行程与费用导出按钮：仅演示操作，不会真实下载旅行数据；完整需求文档的下载功能可用。
- 预订与支付：只提供外部参考入口的说明，不执行任何交易。

```
node tools/smoke-test.js
```

## 图标来源

本地图标来自 [Tabler Icons](https://tabler.io/icons)，版本 3.48.0，MIT 许可全文保存在 `assets/TABLER-LICENSE.txt`。`assets/icons.js` 仅包含选用的图标，运行网页时不请求外部图标资源，也无需安装依赖。

`tools/build-icons.js` 用于更新图标，可读取官方下载的 npm 压缩包；`tools/build-requirements.js` 使用 marked 将总需求文档重新生成为网页。这两项属于维护工具，已生成的网页不需要执行它们。
