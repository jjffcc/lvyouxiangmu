## 1. 产品概览

| 项目 | 当前要求 |
| --- | --- |
| 产品用途 | 帮助用户了解目的地、安排行程、整理购买信息与准备出行 |

| 地域范围 | 先覆盖中国大陆，支持多城市、异地出发和异地返程 |

## 2. 第一版六个模块

每个模块统一按用途、功能与边界说明。

### 2.1 我的旅行

- **用途：** 管理每次旅行及其基本条件。
- **功能：** 创建、保存、编辑、删除旅行；设置目的地、日期、同行者、预算和偏好；支持国内多城市旅行。
- **边界：** 同行者资料用于规划，不等于已实现成员账户、共享权限或多人协作。

### 2.2 目的地特色

- **用途：** 了解城市和具体地方，选择感兴趣的体验。
- **功能：** 城市概览、具体地方详情；人文、自然景观、美食、钓鱼、地理特色等可扩展分类；收藏、查看来源、查看地图。
- **内容：** 背景、体验地点、适合季节、所需时间、参考费用和注意事项；美食分类进入独立城市美食页面。
- **边界：** 本页只用于了解和收藏，不提供加入行程。钓鱼地点的准入、开放与预约条件需有来源，无法确认时标记“待核实”。

### 2.3 城市美食

- **用途：** 了解当地风味，选择和安排用餐体验。
- **功能：** 独立页面展示菜系、代表菜、小吃、区域或商圈及店铺；按早餐、午餐、晚餐、夜宵、小吃组织；按口味、忌口和亲子条件筛选。
- **内容：** 地点、地址、营业时间、参考价格、候餐及预约信息、外部链接；支持收藏和查看地图。
- **边界：** 文化介绍与店铺当前信息分开；营业时间和价格注明来源与适用时间。

### 2.4 行程安排

- **用途：** 手动组织每日活动。
- **功能：** 安排景点、用餐、住宿和交通；调整顺序、锁定安排、填写备注；保存地址，跳转外部地图导航；支持旅行复用。
- **边界：** 第一版行程由用户手动安排，特色页和美食页不提供加入行程，也不做时间重叠检查。自动交通计算、全行程复杂冲突检查、AI 调整和历史版本恢复属于后续规划。

### 2.5 购买信息与费用

- **用途：** 整理外部购买信息，对照预算与实际费用。
- **功能：** 手动记录项目名称、日期、数量、参考价格、实际购买金额、购买链接和备注；按交通、住宿、门票、餐饮、租车及其他分类查看和汇总。
- **边界：** 不提供产品内交易或分账；用户登记不代表网站已核验外部交易。计算规则见第 4.2 节。

### 2.6 出行准备

- **用途：** 集中查看出发前需要准备和核对的内容。
- **功能：** 同行者口味、忌口及亲子需求；行李和准备清单；预约时间、天气查询链接、住宿地址、应急联系人。
- **边界：** 第一版提供天气查询链接；真实天气接入、后台通知及离线缓存属于后续规划。

## 3. 核心使用流程

1. **创建旅行：** 填写目的地、日期、同行者、预算和偏好。
2. **了解目的地：** 查看特色与美食，收藏候选内容。
3. **安排行程：** 手动添加景点、用餐、住宿和交通，填写日期与时段。
4. **调整安排：** 手动排序、编辑备注、锁定需要保留的项目。
5. **记录购买信息：** 保存外部链接，分别填写参考价格与实际购买金额。
6. **准备出行：** 核对预约、住宿地址、联系人和清单，查看天气查询入口。
7. **保存修改：** 保存本次修改，确认刷新后仍可查看。

## 4. 统一规则

### 4.1 信息与交互

| 信息类型 | 展示要求 |
| --- | --- |
| 演示内容 | 明确标记，不作为真实出行参考 |
| 外部参考 | 显示来源、适用时间与查询时间；查询时间不等于适用时间 |
| 用户填写 | 与外部核验结果区分，不能显示为网站已验证 |
| 缺失、过期或冲突 | 保留为空或标记“待核实”，提供可用查询入口 |

- 功能按钮使用对应图案并保留文字，同一操作使用一致图标。
- 无内容或保存失败时，说明原因及可用操作。
- 收藏和点击外部链接均不代表购买、预约成功或产生实际费用。
- 敏感字段默认遮盖；不因页面展示就表示真实账户权限或隐私保护已完成。

### 4.2 金额与计算

| 类型 | 含义 | 汇总规则 |
| --- | --- | --- |
| 预算金额 | 用户计划用于旅行的金额 | 用于对照，不计为实际购买 |
| 参考价格 | 查询或手动填写的预计价格 | 显示来源、时间和估算状态，不自动计入实际费用 |
| 实际购买金额 | 外部购买后由用户手动登记的金额 | 纳入实际费用，不代表已核验外部交易 |

- 以人民币元记录；参考价格和实际购买金额均填写项目总价，数量单独记录，不重复相乘。
- 实际金额未填写时保持为空，不用参考价格替代，不把未知金额写成零。
- 点击购买链接不会自动填写实际金额。
- 同一项目仅汇总一次实际金额；行程与购买信息页面关联同一份金额数据，避免重复累计。
- 展示总预算、已记录实际费用和差额；金额未补齐时提示“费用记录未完整”。修改后重新计算。

### 4.3 复用与删除

- 复用生成新旅行草稿，保留候选地点与安排参考，重新选择日期、预算和同行者。
- 不带入旧购买记录、实际支出、结清记录和敏感附件；动态资料重新核实。结清与附件能力仅在后续实现时适用。
- 删除前说明影响，并说明只影响当前浏览器数据；不声称能删除外部副本。

## 6. 后续规划

| 方向 | 保留的完整规划 |
| --- | --- |
| 智能规划 | AI 表单与对话、节奏优化、多方案比较、自动交通与复杂冲突检查、修改确认、撤销与历史版本恢复 |
| 资料与订单 | 攻略提取、文字／截图／PDF 订单识别、导入确认、重复提示、取消与改期影响、退款记录 |
| 地图与途中服务 | 内嵌地图、路线计算、真实天气、临时改线、网页提醒、日历导出与后台通知 |
| 账户与协作 | 登录、邀请、独立权限、成员草稿、负责人发布、冲突处理与跨设备同步 |
| 费用分摊 | 均摊、指定成员、比例、自定义金额、更正和手动结清记录；仍不执行支付 |

- 外部账户连接和自动订单同步尚未选择或授权。
- 离线地图许可、供应商、配额、费用、真实服务质量与通知送达需在接入前核查。
- 购买记录状态、限制第一批城市、全行程基础时间检查及第五模块改名仍为未接受建议，不加入第一版。
