# 国内旅游规划产品讨论稿

更新日期：2026-10-04。状态：Q1 至 Q29 的产品选择已收拢，等待完整共同理解确认。

## 已确认的定位与边界

- 服务个人自由行、情侣朋友结伴及亲子家庭。
- 先覆盖中国大陆，支持多城市、异地出发和异地返程；数据不足的地区明确提示。
- 首个产品入口为网页。
- 由用户个人建设，先供本人及受邀同行者使用。
- 下列功能全部纳入产品范围，用户后续可以继续补充。纳入范围不代表已确定首版顺序、数据来源或实现方式。
- 提供详细参考信息和预订链接，支持预订跳转、订单导入及统一管理。
- 产品禁止支付操作。旅行费用记录和分账计算不构成支付授权。

## 已纳入范围的功能

| 阶段 | 功能范围 |
| --- | --- |
| 行前准备 | 目的地发现、攻略收藏、内容导入、预算、证件与行李清单 |
| 目的地特色 | 每个旅游地点的人文、自然景观、美食、钓鱼、地理特色等，支持后续扩展分类 |
| 行程规划 | AI 对话、每日路线、地图、交通衔接、住宿位置、餐饮、预约时间、多人偏好 |
| 行中执行 | 导航、天气、提醒、离线行程、记账分账、临时改线、应急信息 |
| 行后整理 | 照片与游记、费用总结、评价、行程复用与分享 |
| 预订信息 | 详细参考链接、外部预订跳转、订单导入、按旅行统一管理 |

## 第二轮已确认的使用规则

用户回复“按照你的建议”，接受上一轮各题所给建议；未给出建议值的预算和时间不视为已确定。

- Q7：表单与 AI 对话双入口；行程可手动修改、拖动排序、替换景点及比较方案。覆盖步行、公交地铁、打车、自驾和城际交通，具体数据与服务能力尚待核查。
- Q8：区分硬性条件与可调整偏好；保留已确认的预订与时间安排。发生冲突时展示替代方案，由用户决定是否分开行动或调整预算。
- Q9：参考信息显示来源、适用日期与查询时间；估算价格明确标注，缺失信息显示“待核实”并提供查询链接；行程提示依赖核实的安排。
- Q10：个人建设，先供本人和受邀同行者使用；账户、同步和分享权限继续细化。
- Q11：订单支持手动录入、粘贴文字、截图和 PDF；识别结果经用户确认后保存；允许手动更新状态，显示信息更新时间。外部账户连接尚未批准或选择。
- Q12：离线保存行程、地址、订单摘要和应急联系人；提供网页提醒与日历导出。浏览器通知和离线地图先核查，尚未承诺完整支持。
- Q13：先交付完整方案和关键页面原型，再根据真实数据接入条件交付可用网站。此轮未给出费用与日期；后续 Q20 已明确需付费时再讨论、暂不设固定上线日期和可点击网页原型。

## 第三轮已确认的使用规则

用户再次回复“按照你的建议”，接受 Q14 至 Q20 的推荐方案。

- Q14：先覆盖中国大陆；支持多城市及异地往返；数据不足明确提示。
- Q15：固定日期和弹性日期；旅行预算包含往返交通、住宿、餐饮、门票、市内交通和备用金，区分全团与人均。亲子条件包含儿童年龄、午休、步行上限、推车、饮食忌口及活动强度。
- Q16：旅行负责人、可编辑成员、只读成员；负责人决定最终方案。订单附件和联系方式单独控制权限；默认仅受邀分享，可撤销访问。
- Q17：AI 调整先展示修改前后、原因和费用影响，用户确认后应用；手动安排可以锁定；支持撤销、版本恢复和冲突选择。
- Q18：交通、住宿、门票、餐饮预约和租车订单；默认保存必要摘要，敏感字段遮盖，原始附件由用户选择保留；重复导入先提示；取消、改期经确认后关联更新；未知截止时间待核实。
- Q19：攻略文字、截图及链接收藏；提取结果确认后加入候选。分账支持均摊、指定成员、比例和自定义金额；照片、游记及费用总结默认私密，支持导出和分享。
- Q20：蓝色、手机优先、兼容电脑的可点击网页原型；覆盖全部已确认功能入口与主要流程；演示数据明确标注。需要付费服务时再讨论，暂不设固定上线日期。

## 第四轮及新增页面规则已确认

在提出 Q27 至 Q29 时，助手明确说明可一并接受 Q21 至 Q29；用户随后回复“按照你的建议”，本轮记录为接受这些建议。

- Q21：账户登录与跨设备同步；成员修改形成草稿，负责人发布正式版本；同时修改发生冲突时保留双方内容，由负责人选择。
- Q22：先满足硬性条件，再按舒适、经济、丰富节奏优化；考虑交通与休息缓冲，并允许调整。无法满足时展示具体原因与替代方案。
- Q23：远期日期显示尚不可预报，准备室内外备选，临近出发更新；天气变化触发改线建议，确认后应用。网页提醒、可设置提前时间、日历导出；浏览器推送按设备能力启用。
- Q24：网页展示路线与交通概览，逐向导航跳转外部地图；定位不可用时手动选择起点。准备清单支持模板、自定义、成员分配和勾选；应急页保存联系人、住宿地址及带来源的附近服务信息。
- Q25：订单变化先提示关联行程和费用，确认后更新；退款单独记录，原支出与更正历史保留；可手动记录已结清，金额变化后展示差额；外部支付。
- Q26：首版离线以查看为主，显示保存版本和时间，联网提示更新；支持行程、费用与资料导出、单次旅行删除。真实 AI/OCR 接入说明上传范围，由用户选择，默认遮盖敏感字段；原型演示内容。
- Q27：城市概览和具体地方详情，支持逐层查看。
- Q28：特色内容包括背景、体验地点、适合季节、所需时间、参考费用、注意事项；可收藏、查看地图、加入行程候选。
- Q29：钓鱼提供体验区域、装备、服务与预约参考链接；开放、准入条件注明来源和适用时间，无法确认标记待核实。
