# 产品共同理解与原型交付确认

日期：2026-10-04。状态：Q1 至 Q29 的选择已记录，本摘要及补充默认规则等待用户整体确认。

## 产品定位

个人建设的国内旅游规划网页，先供本人和受邀同行者使用，服务个人自由行、情侣朋友及亲子家庭。先覆盖中国大陆，支持多城市和异地往返；蓝色视觉、手机优先、兼容电脑。

覆盖行前、行中和行后，完整方案包含 21 个功能模块、18 类页面。功能范围完整纳入，首个实现成果是可点击网页原型，其后按真实数据条件接入可用网站。需要付费服务时再讨论，暂不设固定上线日期。

| 编辑协作 | 可拖动、替换、比较、锁定、撤销与恢复；改线先确认；成员草稿，负责人发布；冲突保留双方内容 |

| 途中 | 天气时效明确、室内外备选、确认后改线；网页提醒、提前时间、日历导出；路线概览与外部地图导航 |
| 准备应急 | 模板、自定义、成员分配和勾选；联系人、住宿地址、带来源的附近服务 |

| AI/OCR | 真实接入说明上传范围，由用户选择，默认遮盖敏感字段；原型使用演示内容 |
| 行后 | 私密照片、游记、评价、费用总结，可导出分享并复用行程 |
| 信息依据 | 来源、适用日期、查询时间；缺失及冲突待核实；钓鱼开放与准入条件必须有可核查来源 |

## 补充默认规则（随本摘要一并确认）

这些用于补齐之前没有单独提问的边界，不冒充用户先前已逐项确认的决定。

1. 旅行分为规划中、待出发、进行中和已结束，可由负责人调整状态；历史旅行可以继续回顾和导出。
2. 复用行程生成新旅行草稿，保留候选地点及安排参考，重新选择日期、预算和成员；不把旧订单、实际支出、结清记录和敏感附件带入新旅行，动态资料重新核实。
3. 方案比较展示时间、交通、预算、步行强度和待核实事项；可计算的指标注明口径与估算状态，不生成无依据的质量分数。
4. 个性化内容通过既有资料库和特色档案维护；个人可补充来源或纠错。资料缺失保留空状态，不以无依据内容填满所有地点与分类。
5. 日历导出标明行程版本；行程修改后提示重新导出及处理旧事件。外部日历导入、重复与更新效果须实际验证，产品不假定能自动修改外部事件。
6. 删除前说明影响，提供先导出选项；云端内容、当前设备离线副本和外部导出文件分别表达，不把云端删除当作所有已下载副本均已删除。
