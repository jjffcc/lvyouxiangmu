# Issue tracker: GitHub

本仓库使用 GitHub Issues 管理需求与问题，使用 `gh` CLI 操作；仓库由当前目录的 GitHub remote 确认。

- 创建：`gh issue create --title "..." --body-file <file>`
- 查看：`gh issue view <number>`
- 列表：`gh issue list`
- 评论、标签和关闭：使用 `gh issue comment`、`gh issue edit`、`gh issue close`
- 工程技能要求将规格发布到 issue tracker 时，创建 GitHub Issue。
- PRs as a request surface: no.
