# 产品验收场景（讨论稿）

日期：2026-10-04。Q1 至 Q29 已收拢，等待完整共同理解确认。这些是未来原型与实现的验收场景，不是当前测试结果；使用虚构信息，真实服务另行验证。

| 编号 | 场景 | 已确认要求形成的预期 |
| --- | --- | --- |
| A01 | 个人填写固定日期或通过聊天创建旅行 | 两种入口均可提供条件、得到可编辑的每日行程；生成演示明确标记 |
| A02 | 两城旅行，出发与返程城市不同 | 同时组织各城活动和城际衔接；缺失交通资料待核实，不伪造班次 |
| A03 | 亲子午休与已确认预约冲突 | 呈现硬条件冲突及替代方案，由用户决定；不擅自删除预约或午休要求 |
| A04 | 酒店价格缺失或营业信息冲突 | 显示来源、适用日期和查询时间，标注估算或待核实，附可用查询入口 |
| A05 | 用户替换景点并要求 AI 调整路线 | 展示修改前后、原因及费用影响；确认后应用，保留锁定安排，可撤销恢复 |
| A06 | 用户导入包含敏感字段的订单截图 | 提取内容先确认；默认遮盖敏感字段，附件是否保留可选；不展示为已核验外部订单 |
| A07 | 同一住宿预订被多次导入 | 先提示可能重复，由用户确认处理；不无提示增加重复记录 |
| A08 | 用户手动更新订单取消或改期 | 提示行程与费用影响，确认后更新；未知截止时间待核实；退款独立记录，保留原支出与更正历史 |
| A09 | 负责人、编辑成员与只读成员查看同一旅行 | 按角色及独立附件、联系方式权限展示操作；负责人决定最终方案；可撤销受邀访问 |
| A10 | 同行者按均摊、指定人、比例或金额分摊费用 | 区分估算和实际支出，显示成员承担金额；不提供支付或转账操作 |
| A11 | 网络断开后查看事先保存的旅行内容 | 已保存的行程、地址、订单摘要和应急联系人可查看，显示版本和保存时间，联网提示更新；首版离线查看 |
| A12 | 旅行完成，整理照片和游记 | 默认私密，支持费用总结、导出、分享及行程复用；复用默认规则随整体方案审阅 |
| A13 | 查看某个旅游地方的特色 | 有人文、自然景观、美食、钓鱼、地理特色等分类，沿用来源与时效规则；没有资料时明确提示，不编造特色 |
| A14 | 钓鱼特色缺少地点准入资料 | 显示待核实及来源适用时间；有资料时展示体验区域、装备、服务和预约参考，外部跳转不支付 |
| A15 | 编辑成员同时修改同一正式行程 | 修改形成草稿，保留双方内容；负责人选择并发布正式版本；演示协作不代表已实现真实同步 |
| A16 | 用户选择舒适、经济或丰富节奏 | 先检验硬性条件，考虑交通与休息缓冲；不可满足时显示具体原因与替代方案 |
| A17 | 旅行日期超出天气预报范围 | 显示尚不可预报，提供室内外备选；临近出发更新，改线须确认 |
| A18 | 用户设置出发、预约或退改提醒 | 支持提前时间和日历导出；浏览器推送按实际能力与许可启用，送达另行实测 |
| A19 | 用户拒绝定位并查看当天路线 | 手动选择起点；路线与交通概览可访问，逐向导航提供外部地图入口 |
| A20 | 家庭成员分工准备行李 | 支持模板、自定义任务、成员分配、勾选；应急联系人和住宿地址可查 |
| A21 | 已结清账目发生退款或分摊更正 | 保留原支出和更正历史，展示成员差额；实际支付在外部处理 |
| A22 | 用户导出资料或删除单次旅行 | 可导出行程、费用与资料；删除影响与设备副本状态分别表达，不能假定已删除外部副本 |
| A23 | 用户启用真实 AI/OCR 上传 | 上传范围明确，由用户选择，默认遮盖敏感字段；原型使用演示内容，无真实上传 |
| A24 | 从城市概览查看具体地方并选择特色 | 支持分层查看，包含背景、地点、季节、所需时间、参考费用及注意事项；可收藏、地图查看、加入候选 |
| A25 | 查看某个城市的独立美食页面 | 含菜系与风味、代表菜与小吃、店铺与体验地点、饮食忌口、用餐时段与预约参考；营业时间与价格带来源和适用时间，缺失时标待核实；可收藏、看地图、加入行程 |

## 验收说明

原型验收检查入口、交互与状态表达；真实 API、同步、权限、通知、缓存与模型能力需在接入后实际验证。旅行生命周期、复用、来源维护、日历版本和删除提示的补充默认规则见 shared-understanding.md，随整体方案审阅。
